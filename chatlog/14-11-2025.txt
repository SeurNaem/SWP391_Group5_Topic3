**User requested:**
"Payment page will fetch vehicle type and license plate, so driver don't have to choose vehicle type anymore"

**Implementation completed:**

### Changes Made to Payment Page (`src/pages/payment/index.jsx`):

1. **Added API Integration:**
   ```jsx
   import { getUserProfile } from '../../service/user.api';
   ```

2. **Enhanced State Management:**
   - Added `licensePlate` field to reservationData
   - Created vehicle type mapping from profile values to display labels

3. **Auto-fetch Function:**
   ```jsx
   const fetchUserVehicleInfo = useCallback(async () => {
       try {
           const vehicleTypeLabels = {
               'electric_car': 'Electric Car',
               'hybrid_car': 'Hybrid Car',
               // ... etc
           };
           
           const userProfile = await getUserProfile();
           if (userProfile?.vehicleType && userProfile?.licensePlate) {
               const displayLabel = vehicleTypeLabels[userProfile.vehicleType] || userProfile.vehicleType;
               setReservationData(prev => ({
                   ...prev,
                   vehicleType: displayLabel,
                   licensePlate: userProfile.licensePlate
               }));
           }
       } catch (error) {
           // Silent fallback - user can still manually select
       }
   }, []);
   ```

4. **UI/UX Improvements:**
   - Auto-populated vehicle type dropdown
   - Disabled vehicle type field when info is loaded from profile
   - Green success alert when vehicle info is loaded
   - License plate display in highlighted box
   - Green background styling for auto-filled fields

5. **Enhanced Display:**
   - License plate shown in confirmation section
   - Vehicle info displayed in reservation details
   - Monospace font for license plate formatting

6. **Error Handling:**
   - Graceful fallback if API fails
   - Manual selection still available as backup
   - No blocking errors for smooth UX

**Result:** Payment page now automatically loads driver's vehicle information from their profile, streamlining the booking process.
