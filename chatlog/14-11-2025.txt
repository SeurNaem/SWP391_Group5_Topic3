## USER REQUEST #12: API Structure Analysis

**User provided actual API response:**
```json
[
  {
    "stationId": 1,
    "chargingPoints": [
      {
        "pointId": 1,
        "connectorType": "CCS",
        "maxPower": 50,
        "status": "reserved", 
        "pricePerKwh": 0.35
      },
      {
        "pointId": 2,
        "connectorType": "CHAdeMO", 
        "maxPower": 50,
        "status": "reserved",
        "pricePerKwh": 0.37
      }
    ]
  }
]
```

**Key Findings:**
1. **`pricePerKwh`** (lowercase 'w') not `pricePerKWh`
2. **Pricing is per charging point**, not per station
3. **Different prices per connector type**
4. **Decimal format** (0.35, 0.37) not formatted strings

**Implementation completed:**

### Updated Pricing Logic (`src/redux/slices/stationSlice.js`):

1. **Station-Level Price Calculation:**
   ```jsx
   price: (() => {
       if (station.chargingPoints && station.chargingPoints.length > 0) {
           const prices = station.chargingPoints
               .map(point => point.pricePerKwh)
               .filter(price => price != null);
           
           if (prices.length > 0) {
               const minPrice = Math.min(...prices);
               const maxPrice = Math.max(...prices);
               
               if (minPrice === maxPrice) {
                   return `$${minPrice.toFixed(2)}/kWh`;
               } else {
                   return `$${minPrice.toFixed(2)}-$${maxPrice.toFixed(2)}/kWh`;
               }
           }
       }
       return '$0.35/kWh'; // Fallback
   })()
   ```

2. **Power Calculation from API:**
   ```jsx
   power: (() => {
       if (station.chargingPoints && station.chargingPoints.length > 0) {
           const totalPower = station.chargingPoints.reduce((sum, point) => 
               sum + (point.maxPower || 22), 0);
           return `${totalPower}kW`;
       }
       return station.totalPoints ? `${station.totalPoints * 22}kW` : '22kW';
   })()
   ```

### Updated Map Display (`src/pages/map/index.jsx`):

1. **Individual Point Pricing:**
   ```jsx
   <Text>{point.pricePerKwh ? `$${point.pricePerKwh.toFixed(2)}/kWh` : 'N/A'}</Text>
   ```

2. **Power Display:**
   ```jsx
   <Text>{point.maxPower ? `${point.maxPower}kW` : point.powerOutput || point.power || 'N/A'}</Text>
   ```

3. **Updated Fallback Values:**
   - Changed from '3,500 VND/kWh' to '$0.35/kWh'
   - Updated both createStation and updateStation functions
