## Issue 5: Station-Specific Charging Points

**User Request**: "check the response body... I think the charging points in Payment page does not belong to the correct stationId. The Charging Point dropdown menu should only display the charging points of the chosen Station"

**Problem Analysis**: The payment page was showing hardcoded charging points instead of the actual charging points that belong to the selected station.

**API Response Structure**:
```json
[
  {
    "stationId": 1,
    "name": "Saigon Central Station",
    "chargingPoints": [
      {
        "pointId": 1,
        "stationId": 1,
        "connectorType": "CCS",
        "maxPower": 50,
        "status": "available",
        "pricePerKwh": 0.35
      }
    ]
  }
]
```

**Solution Implemented**:
1. **Dynamic Charging Points**: Replaced hardcoded `availableChargingPoints` array with data from `stationData.chargingPoints`
2. **Accurate Cost Calculation**: Updated to use actual `pricePerKwh` from selected charging point
3. **Real-time Pricing**: Cost calculation now reflects actual pricing model (per kWh) instead of flat hourly rate
4. **Power Usage Estimation**: Shows estimated kWh usage based on charging point power and duration

**Key Code Changes**:
```javascript
// Before: Hardcoded array
const [availableChargingPoints] = useState([...]);

// After: Dynamic from station data
const availableChargingPoints = stationData?.chargingPoints?.map(point => ({
    id: point.pointId,
    name: `${point.connectorType} - ${point.maxPower}kW`,
    type: point.connectorType,
    power: `${point.maxPower}kW`,
    status: point.status,
    pricePerKwh: point.pricePerKwh
})) || [];

// Updated cost calculation
const estimatedKwhUsage = selectedPoint.maxPower * duration * 0.8; // 80% efficiency
const cost = estimatedKwhUsage * selectedPoint.pricePerKwh;
```

2. **Station ID Validation**: `stationData.stationId` was undefined, causing validation failure
3. **State Management**: Timing issues with React state updates

**Solution Implemented**:

### Step 1: API Payload Correction
```javascript
// Before: Complex payload
const reservationPayload = {
    stationId: stationData.id,

    vehicleType: reservationData.vehicleType,
    startTime: reservationData.startTime,
    endTime: dayjs(reservationData.startTime).add(chargingDuration, 'hour').toISOString(),
    estimatedCost: estimatedCost

    pointId: reservationData.selectedChargingPoint
```
